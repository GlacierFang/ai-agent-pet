# 0.5.10

修打地鼠「旋钮转不到地鼠」。

## 现象

打地鼠的六格里，地鼠亮着红方块，旋钮转起来**光标不动**（或者只在一头打转），
永远转不到地鼠那一格，也打不中。

## 原因

引擎有两处缺陷：

1. **fx 名字映射表漏了 `move_cell`** —— 能力表里写着支持，名字表里却没有。
   包里的移动效果被解析成 `GAME_FX_NONE` 直接丢弃，光标从来没动过。
   而且不报错：包照样装上，菜单里照样出现，就是不响。
2. **`move_cell` 越界是「夹在边内」而不是首尾相接** —— 六格环上光标卡在两头，
   永远转不到对面那格。

另外，fx / 事件 / 能力三张名字表此前分散在固件源码、`tools/lint_packs.py`、
`tools/gen_host_scene.py` 三处，彼此可能不同源。

## 改动

### 引擎

- **fx / 事件 / 能力三张表收成单一真相**。名字表放在 `game_comp.c`，
  工具和测试经 `tools/game_names.py` 读它。
- **认不出的效果名 / 事件名报错**，不再悄悄丢掉。
- **网格加 `wrap`**：越界首尾相接，走过头绕回另一头。
- **新增 `advance_cell`**：沿 +x 前进若干格，不看输入方向。
- **格子实体加 `outline`**：画成边框而不是实心（光标用）。
  边框式实体**最后画** —— 压在实体上面也要看得见，
  实心地鼠画在光标之后会把光标边框盖掉，玩家就不知道选中的是哪一格。

### 游戏包（打地鼠重做）

- **六格环**：旋转在六格之间往复（首尾相接，没有死角），光标是白框。
- **短按敲击**当前格：地鼠在那一格就命中加 10 分、地鼠缩回；否则空敲不加分。
- 地鼠按 1.8 秒的节奏轮换格位（路径可预测，能预判它往哪走）。
- 长按 600ms 退出菜单，沿用现有规则不变。

## 兼容性

- OTA 协议、协议版本、握手、屏保、后台 API 未变。
- 消砖块 / 贪吃蛇 / 骰子三个游戏的任何行为未变。
- 老固件（0.5.9 及更早）认不了 `wrap` / `outline`，会拒收新的打地鼠包
  （不写盘、回 `packAck ok=false`、菜单里不出现，不黑屏不崩）。
  **升级到 0.5.10 之后，下次握手时新包才会装上。**

## 验证

- **宿主侧引擎测试**（`tests/fw_host/test_whack_engine.c`）26 项全过：
  光标转格、六格首尾相接（从第一格往左转一格到最后一格）、
  顺时针转一圈走遍全部六格、地鼠轮换格位、敲击要碰到才算、
  命中后地鼠缩回、名字表护栏（`move_cell` 必须查得到）。
- **新增 `tests/test_game_names.py`** 6 条：名字表与 `game.h` 的码一一对应、
  pack 用到的每个 fx / 事件固件都认识、能力都在固件能力表里、
  场景生成器不许再写死一份 fx 表。
- 全量 510 passed，`tools/lint_packs.py` 全过，`tools/check_docs.py` 通过。
- **已在真机上验证通过**（11-13）—— 设备 OTA 升到 0.5.10 后，新打地鼠包正常装上、
  菜单里出现；旋钮在六格间循环选格（首尾相接，没有死角），短按敲击命中地鼠加 10 分、
  空敲不加分，地鼠按节奏轮换格位，「你赢了」遮罩正常弹出。

## 资产说明

| 文件 | 用途 |
|---|---|
| `petd.bin` | **app 分区镜像**。OTA 推这个 |
| `merged-binary.bin` | 整片镜像（含 bootloader + 分区表 + app）。地址 `0x0` |
| `uf2.bin` | 给支持 UF2 的设备用 |
| `flash_args` / `flasher_args.json` | esptool / idf.py flash 的参数 |

整片刷参数：地址 `0x0`、SPI SPEED `80MHz`、SPI MODE `DIO`、**不按 ERASE**（保住 NVS 里的 Wi-Fi 配网信息）。

> ⚠️ **`merged-binary.bin` 绝不能当 OTA 的 app 镜像登记** —— 它是从 `0x0` 起的整片布局，OTA 只写 app 分区。登记错了一次就是砖。
