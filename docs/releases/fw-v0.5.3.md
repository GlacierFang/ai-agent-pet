## 0.5.3

这一版只做贪吃蛇，不带别的功能。

### 修掉的三件事

**① 旋转转向转的不是 90°**

引擎里 `heading` 是方向序号（0 上 1 右 2 下 3 左），但 `turn` 效果把角度直接加进去再 `% 4`：

```
90 % 4 == 2
-90 % 4 == -2 ≡ 2
```

左右旋转算出来是同一个值，而且那个值是 180° 掉头。蛇一直在对着自己的身体掉头 —— 玩家转多少圈都是死，「旋转转向」这个操作从来没成立过。

改成按方向序号 ±1 走，一次手势最多 90°，快甩旋钮不会把蛇转一整圈。

**② 动得太快**

`speed` 的单位是格/秒。原来的 `speed: 6` 是每秒 6 格（约 166ms 一格），在 12px 的格子上快到看不清。降到 3 格/秒。

**③ 碰撞框和画面对不上**

网格实体有三套几何口径：坐标换算用 `grid.cell`，绘制用 `grid.cell_w/cell_h`，碰撞与食物落点按整数格占用判断。蛇是正方形所以暂时等价，但任何一处偏移都会让玩家看到「还没碰到就判死」。

现在统一到 `grid_cell_size()` 一处：

- 蛇头画满一格，跟碰撞盒一模一样
- 蛇身每节画小一圈，节与节之间留缝，看得出是几节
- 食物也画小一圈
- 边框画在场地外侧一像素 —— 蛇头贴边时正好贴住边框线

### 顺手改掉的

**「按下掉头」整个去掉**

掉头在贪吃蛇里没有意义：掉头后第一格就是自己的身体，必然自撞。引擎原有的 `reverse` 效果遇到这种情况会直接忽略掉头，玩家只会觉得「按了没反应」。

贪吃蛇现在只留一个操作：**旋转转向 · 长按退出**。结束遮罩里的「按一下返回」也改成「长按退出」。

**已装的游戏包永远不更新**

设备只按 ID 判重，不比对内容 —— 服务端改了 pack（比如蛇的速度），设备本地那份还是旧的，刷了新固件也玩不到新版本。后台现在在握手时和手动推送时都把启用的包重推一遍，设备覆盖写盘。

**判负之后蛇还在动**

引擎判负后没有冻结，蛇继续走，玩家会以为「明明死了还在动」。现在 `state != 0` 就停止推进。

### 刷机

跟之前一样：地址 `0x0`、SPI SPEED 80MHz、SPI MODE DIO。

**不按 ERASE** —— 保住 NVS 里已存的 Wi-Fi 配网信息。

### 刷完必做一步

贪吃蛇是游戏包，**不在固件里**。后台（`:18860/admin/`）在设备连上时会自动把最新的 snake pack 推下去（这一版新加的），所以正常情况下不用管。

如果屏上还是老的速度，说明设备拿到的是旧包：在后台「游戏」页手动点一次推送即可。
