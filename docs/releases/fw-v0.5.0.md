## 0.5.0

- **引擎新增四个通用原语** —— `vel`（速度与加速度）、`collide`（像素空间碰撞与反弹）、`bounds`（撞边界反弹）、`pattern`（网格图样）
- **消砖块** —— 新增 `petd/packs/brickout.json`：旋钮移挡板，按下发球，砖清空即通关
- **屏幕软件压暗** —— 背光不可控时压内容，新增档位
- 修复：游戏包解析的临时对象改为堆分配（此前约占 15KB 栈空间，在小栈任务里会溢出）
- 修复：物体与障碍重叠且已在往分离方向移动时不再反射速度；撞墙只翻朝墙里走的那一侧速度

## 刷写

整片镜像（0x0 起，含 bootloader）：

```bash
esptool.py -p <串口> -b 460800 write_flash 0x0 merged-binary.bin
```

只换应用分区（分区表未变时可用，偏移 0x20000）：用 `petd.bin`。

UF2：`uf2.bin`（拖进设备即可，无需命令行）。

## 操作

- **短按**打开游戏菜单
- **长按**退出游戏
- 游戏列表在后台「游戏」页勾选，勾完即刻下发
- 消砖块：旋钮左右移挡板，短按发球

## 刷完怎么确认

后台「设备」状态里的固件版本应显示 **0.5.0**。

消砖块需要 0.5.0 固件 —— 旧固件没有 `collide`/`bounds`/`pattern` 能力，服务端下发时会被设备拒绝。
