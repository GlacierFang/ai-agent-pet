# 部署手册

> 🟡 **骨架文档** —— 步骤顺序已定，但 petd 和固件代码尚未落地，各步的**预期输出**等实测后补。
> 硬件细节见 [硬件指南](硬件指南.md)，固件细节见 [固件构建](固件构建.md)。

## 你需要什么

| 类别 | 内容 | 约 |
|---|---|---|
| 硬件 | ESP32-S3-DevKitC-1 (N8R8)、2.4" ST7789 240×320、KY-040 旋转编码器 | ¥41 |
| 线材 | 杜邦线、排针 | ¥10 |
| 主机 | 一台跑着 OpenClaw gateway 的 Linux 机器（本项目在树莓派 4B 上开发） | — |
| 软件 | ESP-IDF v5.5.x（编译固件）、Python 3.10+（跑 petd） | — |

**不需要**：PCB 打板、焊接、示波器。

## 步骤 0 · 准备

1. 按 [硬件指南](硬件指南.md) 的 BOM 买齐三块料
2. **到货必测项 —— ⚠️ 先测再接线**：ST7789 的 8 针顺序、排针性别与杜邦线匹配、KY-040 每圈步数、抖动与回差
3. 装 ESP-IDF：`idf.py --version` 要有输出 🟡 待实测

## 步骤 1 · 先跑通 petd（不用硬件）

**先证明软件链路是通的，再碰硬件。**

```bash
pip install ai-agent-pet          # 🟡 待发布
ai-agent-pet --port 18860 --mock-device
```

**预期**：
- 终端打印 gateway 连接成功 + 拿到的 scope
- 浏览器打开 mock 设备页 → 看到宠物在呼吸

**出错查**：[故障排查](故障排查.md)

## 步骤 2 · 让 petd 认到 gateway

petd 需要 gateway 的连接配方（token + client id + mode + role + scope）。🟢 配方已实测 —— 见 [状态语义](状态语义.md)。

**预期**：终端打印「订阅到 N 个会话」，状态随会话变化而变。

## 步骤 3 · 接线

按 [硬件指南](硬件指南.md) 接线。

**⚠️ 安全规则（不可违反）**：
- **烧录时只接 PC**，不接充电头
- **运行时只接充电头**，不接 PC
- **两个 USB-C 的 5V 是相通的** —— 同时接会烧板

## 步骤 4 · 编译与烧录固件

见 [固件构建](固件构建.md)。

```bash
cd firmware
idf.py set-target esp32s3
idf.py build
idf.py flash
```

🟡 具体 offset 与文件名待实测（以 `idf.py flash` 输出为准）。

## 步骤 5 · 设备配网 + 找 petd

- 设备用 mDNS 广播 `petd.local`（🟡 待实现）
- petd 侧能看到设备上线

## 步骤 6 · 看到宠物动起来

**预期**：屏幕显示表情；转旋钮切会话；短按切页；长按刷新。

## 步骤 7 · 后台控制台

打开 `http://<pi>:18860/admin/` —— 见 [后台控制台](后台控制台.md)。

## 常见卡点

| 症状 | 去哪查 |
|---|---|
| 屏幕全黑 | [故障排查](故障排查.md) · 黑屏 |
| 花屏 / 红蓝互换 | [故障排查](故障排查.md) · 花屏（字节序 / SPI 频率） |
| 设备连不上 | mDNS / Wi-Fi 配网 |
| 宠物不反映会话状态 | gateway scope / 状态映射 |
| 解码慢 / 掉帧 | SPI 频率、TjpgDec 档位 |
| 列表页位置不对 | 状态语义 · 列表页页数 |

## 升级固件

见 [后台控制台](后台控制台.md) 的「固件与更新」。OTA 在固件实现前不可用，用 USB 烧录。

## 卸载

- 停止 petd
- 设备上电时按住 BOOT 进下载模式，用 esptool 擦除 flash
- 删除本地配置目录
