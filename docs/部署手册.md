## 七步

### 1 · 拿到代码

```bash
git clone https://github.com/GlacierFang/ai-agent-pet.git
cd ai-agent-pet
pip install -r requirements.txt      # 或 pip install -e .
```

> 💡 pip 装不上？环境里设了全局 `HTTP_PROXY` 时 PyPI 会 403。
> 用 `python3 -m venv --system-site-packages .venv` 复用系统已装的依赖即可。

### 2 · 起 petd

petd 需要一个 gateway token 才认得你的 OpenClaw 会话。token 在 OpenClaw 的配置文件里：

```bash
# 打印出来，复制下面那串
python3 -c "import json,os;print(json.load(open(os.path.expanduser('~/.openclaw/openclaw.json')))['gateway']['auth']['token'])"
```

```bash
export PETD_GATEWAY_TOKEN=把上面那串粘进来
python3 -m petd --port 18860
```

**预期输出**：

```
[petd] 监听 0.0.0.0:18860
[petd] 控制台 http://0.0.0.0:18860/admin/
... petd.gateway  gateway 已连接，scope=['operator.read']
... petd.app      订阅到 N 个会话
```

看到 `gateway 已连接` 就是通了。看不到 → [故障排查](故障排查.md)。

> 💡 token 也可以写进 `petd/data/secrets.json`（key 是 `gatewayToken`），适合不想每次 export 的场景。

### 3 · 接线

按 [硬件指南](硬件指南.md) 的接线表接三样：屏、编码器、电源。

**⚠️ 安全规则（不可违反）**：

- **烧录时只接 PC**，不接充电头
- **运行时只接充电头**，不接 PC
- **两个 USB-C 的 5V 是相通的** —— 同时接会烧板
- 屏和编码器的 VCC 都接 **3.3V 不是 5V**

### 4 · 烧录固件

**不用装 ESP-IDF** —— 直接用预编译的固件：

1. 打开 [Releases](https://github.com/GlacierFang/ai-agent-pet/releases) 下 `fw-v0.4.2` 的 **`merged-binary.bin`**
2. 插开发板的 **USB-to-UART 口**（板上有两个 USB 口，用桥接芯片那个，不是原生 USB 口）
3. 只接 PC，**不接充电头**
4. 刷（在 `merged-binary.bin` 所在目录执行）：

**Linux**

```bash
python3 -m pip install esptool
python3 -m esptool --chip esp32s3 --port /dev/ttyUSB0 write-flash 0x0 merged-binary.bin
```

**Windows**

```powershell
py -m pip install esptool
py -m esptool --chip esp32s3 --port COM5 write-flash 0x0 merged-binary.bin
```

> **Windows 第一次刷多做两件事**
>
> - **装串口驱动** —— 官方 DevKitC-1 的桥接芯片是 CP210x，驱动在
>   <https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers>；
>   改版克隆板常见 CH343 / CH340（沁恒），驱动在
>   <https://www.wch.cn/downloads/CH343SER_EXE.html>，
>   不认就装 <https://www.wch.cn/downloads/CH34X_EXE.html>（CH34x 全系列）。
>   装错的表现是设备管理器里带黄色感叹号
> - **查 COM 口号** —— 插上板子后打开「设备管理器 → 端口(COM 和 LPT)」，
>   记下 `USB-SERIAL CH340 (COM5)` 这类名字里的数字，填进 `--port`
> - **插哪个口** —— 用**USB 转串口那个口**（官方板丝印 `UART`），不是原生 USB 口。
>   原生 USB 复位后会重新枚举，串口会掉
>
> 命令行也能查：`py -m serial.tools.list_ports`
>
> 没有 `py` 命令就用 `python`（Windows 上装完 Python 一般两个都有）。

> ⚠️ **esptool 大版本之间命令名变了**：v5 用 `write-flash`（连字符），
> v4 用 `write_flash`（下划线）。先 `python -m esptool version` 看一眼再敲命令。
> 压缩默认就是开的，**不用再加 `-z`**。

> ⚠️ 下 `fw-v0.4.2`，**别下更早的版本** —— `fw-v0.1.0` 的 Wi-Fi 凭据是编译时写死的，刷完连不上网；
> `fw-v0.2.0` 的颜色反相默认发反了，配网屏还是错字；
> `fw-v0.3.0` 推帧只能推两帧就停死，画面每行块左侧 16 列还会错位；
> `fw-v0.4.0` 的配网引导屏画不出字（一行只剩最后一个字符），热点名的小写字母是空白，手机 Wi-Fi 列表里对不上。
>
> 刷完开机，**进配网模式时先亮 5 秒色条**（左上角白色 L 形角标 + 红绿蓝白四条带）。
> 对着色条一眼能看出颜色、方向、字节序对不对 —— 详见 [硬件指南](硬件指南.md)。
>
> 想改固件自己编译 → [固件构建](固件构建.md)。
>
> **不支持 OTA 升级** —— 固件只能 USB 烧录。

### 5 · 设备配网

固件自带配网页面，**不用改代码不用重新编译**：

1. 设备开机，屏幕显示 `PETD SETUP`，上面有：
   - **热点名** `petd-setup-XXXX`
   - **密码**（屏幕上的 13 位）
   - **配网页地址** `192.168.4.1`
2. 手机连上这个热点，浏览器打开 <http://192.168.4.1>
3. 填家里的 Wi-Fi 名称密码 → 点「保存并重启」
   - 「宠物服务端地址」**留空** —— 默认走 mDNS 找 petd

配好的凭据存在设备 NVS 里，断电不丢，正常只配一次。

### 6 · 设备找到 petd

设备重启后自己解析 `petd.local` 找到服务端。

> ⚠️ **必须同一个网段。** mDNS 是组播广播，**不跨路由器、不跨 VLAN**。
> 设备连的是 2.4G Wi-Fi、你的电脑接的是网线 —— 这两个通常不在一个网段，设备就找不到 petd。
> **先把设备和电脑连到同一个 Wi-Fi 热点上试。**
>
> 一台机器有两张网卡（eth0 / wlan0）时，确认设备在 petd 所在的那张网卡上。

确认 petd 起来了：

```bash
curl -s http://127.0.0.1:18860/admin/api/session
```

设备那边则看后台「连接与诊断」页的设备状态。

### 7 · 看到宠物，打开后台

**预期**：屏幕显示宠物状态。

旋钮的默认手势：

| 手势 | 干什么 |
|---|---|
| 旋转 | 翻到下一张内容卡 |
| 按住 + 旋转 | 切换信息密度（简洁 / 标准 / 详细） |
| 长按 | 刷新会话状态 |
| 短按 | 摇骰子 |

改映射在 `petd/data/gestures.json`，重启 petd 生效，**不用刷固件** —— 详见 [旋钮](旋钮.md)。

后台在 <http://127.0.0.1:18860/admin/>。

**第一次打开会让你设一个后台口令**（只存 scrypt 哈希）。设完才进得去。

六页签：

| 页签 | 内容 |
|---|---|
| 我的宠物 | 宠物状态、设备画面预览、会话列表 |
| 宠物库 | 换一只宠物，画一只自己的；换背景、传自己的背景 |
| 宠物设定 | 功能勾选、停留时长、信息密度、睡觉时段、相册 |
| 连接与诊断 | 连接状态、原始遥测、诊断日志、旋钮手势 |
| 文档 | 仓库里的文档直接在控制台里读 |
| 使用说明 | 说明书 |

口令规则和三种模式 → [后台控制台](后台控制台.md)。

## 常见卡点

| 症状 | 去哪查 |
|---|---|
| `gateway 连接失败(403)` | 环境代理变量 → [故障排查](故障排查.md) |
| `missing scope: operator.read` | token 不对 → [故障排查](故障排查.md) |
| 屏幕全黑 / 花屏 | [故障排查](故障排查.md) |
| 设备连不上 petd | **网段** / mDNS → [故障排查](故障排查.md) |
| 宠物不反映会话状态 | gateway scope / 状态映射 → [状态语义](状态语义.md) |
| 解码慢 / 掉帧 | SPI 频率、TjpgDec 档位 → [固件构建](固件构建.md) |

## 卸载

- 停止 petd
- 设备上电时按住 BOOT 进下载模式，用 esptool 擦除 flash
  （Linux `python3 -m esptool --chip esp32s3 --port /dev/ttyUSB0 erase-flash`，
  Windows `py -m esptool --chip esp32s3 --port COM5 erase-flash`）
- 删除 `petd/data/` 目录
