## 七步

### 1 · 拿到代码

```bash
git clone https://github.com/GlacierFang/ai-agent-pet.git
cd ai-agent-pet
pip install -r requirements.txt      # 或 pip install -e .
```

> 💡 pip 装不上？环境里设了全局 `HTTP_PROXY` 时 PyPI 会 403。
> 用 `python3 -m venv --system-site-packages .venv` 复用系统已装的依赖即可。

### 2 · 起 petd

petd 需要一个 gateway token 才认得你的 OpenClaw 会话。token 在 OpenClaw 的配置文件里：

```bash
# 打印出来，复制下面那串
python3 -c "import json,os;print(json.load(open(os.path.expanduser('~/.openclaw/openclaw.json')))['gateway']['auth']['token'])"
```

```bash
export PETD_GATEWAY_TOKEN=把上面那串粘进来
python3 -m petd --port 18860
```

**预期输出**：

```
[petd] 监听 0.0.0.0:18860
[petd] 控制台 http://0.0.0.0:18860/admin/
... petd.gateway  gateway 已连接，scope=['operator.read', 'operator.write']
... petd.app      订阅到 N 个会话
```

看到 `gateway 已连接` 就是通了。看不到 → [故障排查](故障排查.md)。

> 💡 token 也可以写进 `petd/data/secrets.json`（key 是 `gatewayToken`），适合不想每次 export 的场景。
> 也可以在后台「连接与诊断」页直接填 —— 落进同一个文件，改完自动重连。
> 两种填法怎么选、什么权限 —— 见 [网关接入](网关接入.md)。

### 3 · 接线

按 [硬件指南](硬件指南.md) 的接线表接三样：屏、编码器、电源。

**⚠️ 安全规则（不可违反）**：

- **烧录时只接 PC**，不接充电头
- **运行时只接充电头**，不接 PC
- **两个 USB-C 的 5V 是相通的** —— 同时接会烧板
- 屏和编码器的 VCC 都接 **3.3V 不是 5V**

### 4 · 烧录固件

**不用装 ESP-IDF，也不用敲命令** —— Windows 用乐鑫官方的图形工具刷预编译固件。

### Windows · 乐鑫官方 Flash Download Tools（推荐）

1. 从 [Releases](https://github.com/GlacierFang/ai-agent-pet/releases) 下载最新版本的 **`merged-binary.bin`**
2. 下载乐鑫官方工具 **Flash Download Tools**（Windows 版）→ [乐鑫「支持 → 下载 → 工具」页](https://www.espressif.com/zh-hans/support/download/other-tools)；工具用法官方另有[中文说明](https://docs.espressif.com/projects/esp-test-tools/zh_CN/latest/esp32/production_stage/tools/flash_download_tool.html)
3. **装串口驱动**（只装一次）
   - 官方 DevKitC-1 的桥接芯片是 CP210x → [Silabs CP210x 驱动](https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers)
   - 改版克隆板常见 CH343 / CH340（沁恒）→ [沁恒 CH343SER](https://www.wch.cn/downloads/CH343SER_EXE.html)，不认就装[沁恒 CH34X 全系列](https://www.wch.cn/downloads/CH34X_EXE.html)
   - 装错的表现是设备管理器里带黄色感叹号
4. 插开发板的 **UART 口**（官方板丝印 `UART`，USB 转串口那个；**不是**原生 `USB` 口）—— **只接 PC，不接充电头**
5. 打开「设备管理器 → 端口(COM 和 LPT)」，记下串口号（`USB-SERIAL CH340 (COM5)` 这类名字里的数字）
6. 双击 `flash_download_tool.exe`：`ChipType` 选 **ESP32-S3**，`WorkMode` 选 **develop**，`LoadMode` 选 **UART**，点 `OK`
7. 填参数：

   | 配置项 | 填什么 |
   |---|---|
   | 固件文件路径 | 勾选**第一行**，载入下载的 `merged-binary.bin` |
   | 烧录起始地址 | **`0x0`** —— 合并固件必须从 0x0 开始刷 |
   | SPI SPEED | `80MHz` |
   | SPI MODE | `DIO` |
   | COM 端口 | 设备管理器里看到的那个（`COM5`） |
   | BAUD | `921600`（刷得慢就换 `115200`） |

8. 点左下角 **`START`** 开始烧录
   - 进度条没动、下方提示「等待上电同步」→ **按住 BOOT 不放** → **短按一下 RST** → **松开 BOOT**，进度条就会走起来
   - 进度条走满、左下角出现绿色 **`FINISH`** = 烧录成功
9. 点 `STOP` 释放串口，按一下开发板的 **RST** 重启设备

> 💡 **`ERASE` 要不要按**：不用按 —— 不按能保住设备 NVS 里已经存好的 Wi-Fi 配网信息，按了就得重新配网。只有遇到「配置冲突、刷完不认」时才按。

> ⚠️ **只接 PC，不接充电头** —— DevKitC-1 两个 USB-C 的 5V 在板上相通，同时接会 5V 回灌烧板。

### 4.5 · 以后不用再插 USB —— OTA

固件 **0.5.7** 之后，升级可以在后台点一下完成，不用再插 USB。

1. 后台「固件」页 → 登记一个固件（上传 `petd.bin`，或填一个 URL）
2. 确认页面上出现「可用 0.5.8」这类提示
3. 点「升级到」—— petd 分片下发，设备写进另一个分区，校验通过后自己重启

> ⚠️ **0.5.7 这一版仍然要整片刷** —— 0.5.4 改了 bootloader（加了自动回滚），而 0.5.4 到 0.5.6 的 hello 握手有缺陷。刷完 0.5.7 之后，以后都能纯 OTA 升级了。

> 💡 **OTA 只认 app 镜像** —— 登记的必须是 `petd.bin`，不是 `merged-binary.bin`。后者是含 0x0 头的整片镜像，会覆盖分区表。

### 命令行方式（备选）

**Linux**

```bash
python3 -m pip install esptool
python3 -m esptool --chip esp32s3 --port /dev/ttyUSB0 write-flash 0x0 merged-binary.bin
```

**Windows**

```powershell
py -m pip install esptool
py -m esptool --chip esp32s3 --port COM5 write-flash 0x0 merged-binary.bin
```

> 💡 **命令行也能查串口**：`py -m serial.tools.list_ports`。
> 没有 `py` 命令就用 `python`（Windows 上装完 Python 一般两个都有）。

> ⚠️ **esptool 大版本之间命令名变了**：v5 用 `write-flash`（连字符），
> v4 用 `write_flash`（下划线）。先 `python -m esptool version` 看一眼再敲命令。
> 压缩默认就是开的，**不用再加 `-z`**。

> ⚠️ 下**最新**那个 Release（当前是 `fw-v0.5.7`），**别下更早的版本** —— `fw-v0.1.0` 的 Wi-Fi 凭据是编译时写死的，刷完连不上网；
> `fw-v0.4.2` 的「扫描附近的 Wi-Fi」扫不出热点，进扫描还会把手机的 `192.168.4.1` 连接拉断；
> `fw-v0.2.0` 的颜色反相默认发反了，配网屏还是错字；
> `fw-v0.3.0` 推帧只能推两帧就停死，画面每行块左侧 16 列还会错位；
> `fw-v0.4.0` 的配网引导屏画不出字（一行只剩最后一个字符），热点名的小写字母是空白，手机 Wi-Fi 列表里对不上。
>
> ⚠️ **`fw-v0.4.8` 已作废** —— 有栈溢出隐患，别用这一版。

> ⚠️ **`fw-v0.5.0` 已作废** —— 装游戏包时撑爆 WebSocket 回调栈，设备会反复重启
> （屏上在 CONNECTING 和宠物卡之间刷屏）。用 `fw-v0.5.2` 或更新版本。

> ⚠️ **`fw-v0.5.4` / `fw-v0.5.5` / `fw-v0.5.6` 已作废** —— hello 握手撑爆 WebSocket
> 回调栈，设备连上了服务器却发不出 hello，屏上永远 CONNECTING。用 `fw-v0.5.7`。

> 刷完开机，**进配网模式时先亮 5 秒色条**（左上角白色 L 形角标 + 红绿蓝白四条带）。
> 已经配过 Wi-Fi 的设备开机直接进 `CONNECTING`，不亮色条 —— 这不是刷失败。
> 对着色条一眼能看出颜色、方向、字节序对不对 —— 详见 [硬件指南](硬件指南.md)。
>
> 想改固件自己编译 → [固件构建](固件构建.md)。
>
> 这一版（0.5.7）之后就能纯 OTA 了 —— 但这一次仍然要整片刷：0.5.4 改了 bootloader，
> 而 0.5.4 到 0.5.6 的握手有缺陷。

### 5 · 设备配网

固件自带配网页面，**不用改代码不用重新编译**：

1. 设备开机，屏幕显示 `PETD SETUP`，上面有：
   - **热点名** `petd-setup-XXXX`
   - **密码**（屏幕上的 13 位）
   - **配网页地址** `192.168.4.1`
2. 手机连上这个热点，浏览器打开 <http://192.168.4.1>
3. 填家里的 Wi-Fi 名称密码 → 点「保存并重启」
   - 「电脑服务器 IP 地址」**填 petd 所在那台机器的局域网 IP** —— 
     后台首页「设备怎么找到这台电脑」那栏会直接列出可以填的地址

配好的凭据存在设备 NVS 里，断电不丢，正常只配一次。

### 6 · 设备找到 petd

设备连上 Wi-Fi 后，用刚才填的 IP 连服务端。

> ⚠️ **必须同一个网段。** 设备连的是 2.4G Wi-Fi、你的电脑接的是网线 ——
> 这两个通常不在一个网段，设备就找不到 petd。
> **先把设备和电脑连到同一个 Wi-Fi 热点上试。**
>
> 一台机器有两张网卡（eth0 / wlan0）时，确认设备在 petd 所在的那张网卡上。
>
> **端口也写进去**（形如 `192.168.1.100:18860`）—— 你的 petd 未必跑在默认端口上。
> 设备会把地址里的端口拆出来真的连那个端口；不写端口就用默认端口。

确认 petd 起来了：

```bash
curl -s http://127.0.0.1:18860/admin/api/session
```

设备那边则看后台「连接与诊断」页的设备状态。

### 7 · 看到宠物，打开后台

**预期**：屏幕显示宠物状态。

旋钮的默认手势：

| 手势 | 干什么 |
|---|---|
| 旋转 | 翻到下一张内容卡 |
| 按住 + 旋转 | 切换信息密度（简洁 / 标准 / 详细） |
| 长按 | 刷新会话状态 |
| 短按 | 摇骰子 |

改映射在 `petd/data/gestures.json`，重启 petd 生效，**不用刷固件** —— 详见 [旋钮](旋钮.md)。

后台在 <http://127.0.0.1:18860/admin/>。

**第一次打开会让你设一个后台口令**（只存 scrypt 哈希）。设完才进得去。

六页签：

| 页签 | 内容 |
|---|---|
| 我的宠物 | 宠物状态、设备画面预览、会话列表 |
| 宠物库 | 换一只宠物，画一只自己的；换背景、传自己的背景；另有一段是卡片背景（内容卡和骰子铺的底，各有各的图） |
| 宠物设定 | 功能勾选、停留时长、信息密度、睡觉时段、相册 |
| 连接与诊断 | 连接状态、原始遥测、诊断日志、旋钮手势 |
| 文档 | 仓库里的文档直接在控制台里读 |
| 使用说明 | 说明书 |

口令规则和三种模式 → [后台控制台](后台控制台.md)。

## 常见卡点

| 症状 | 去哪查 |
|---|---|
| `gateway 连接失败(403)` | 环境代理变量 → [故障排查](故障排查.md) |

## 卸载

- 停止 petd
- 设备上电时按住 BOOT 进下载模式，用 esptool 擦除 flash
  （Linux `python3 -m esptool --chip esp32s3 --port /dev/ttyUSB0 erase-flash`，
  Windows `py -m esptool --chip esp32s3 --port COM5 erase-flash`）
- 删除 `petd/data/` 目录
