# 美术规范

## 核心规格

| 项 | 值 |
|---|---|
| 分辨率 | **240 × 320**（竖屏） |
| 格式 | PNG，带 alpha |
| 帧数 | **每态恰好一张** —— 不分帧、不做动画 |
| 原始尺寸 | **随意** —— 会被裁切缩放到 240×320，**不拉伸** |
| 透明底 | 最好（宠物要叠在背景上） |

## 目录与命名

```
skins/
└── default/
    ├── idle.png
    ├── working.png
    ├── waiting.png
    ├── done.png
    ├── error.png
    └── sleeping.png
```

**规则**：
- 一个皮肤文件夹 = 六个状态各一张图，文件名就是状态名 + `.png`
- 状态名必须与 [状态语义](状态语义.md) 里的状态名一致
- 同一状态只有一张 —— 想要多帧就是走错模型了
- 用户自己建的放在 `petd/data/skins/<name>/`，同名时盖掉仓库那份

六张图要**同尺寸、同角色、同位置** —— 状态切换时脸不能跳。
主体画在中间偏下：紧凑档表情区只有 140 高，上下会被裁掉。

## 三种信息密度

旋钮可以切换密度档位（按住+旋转），同一套美术要适配三档：

| 档位 | 表情区高度 | 文字 | 用途 |
|---|---|---|---|
| 紧凑 | 240×140 | 仅一行状态词 | 省空间，远处也能看 |
| 标准 | 240×200 | 状态词 + 一行副标题 | 默认 |
| 大号 | 240×280 | 状态词 + 副标题 + 会话名 | 近距离 / 无障碍 |

**实现上不是三套美术** —— 是同一张图在不同版式里缩放排布。表情区高度变了，文字区就跟着变。

## 版式

```
┌────────────────────────┐
│                        │
│      表情区             │  ← 按密度档位变高
│                        │
│                        │
├────────────────────────┤
│  状态文字区             │  ← Pi 侧 Pillow 渲染
│  「正在跑工具」          │
│  「my-train 后端」       │
└────────────────────────┘
```

- 表情区：240 × 140 / 200 / 280（紧凑 / 标准 / 大号）
- 文字区：剩余高度
- 文字**由 petd 渲染**，不要求美术出带字的图

## 状态怎么区分

表情区贴的是那一态的图，六态各一张。**不做帧动画** —— 状态跳变时直接换图。

| 状态 | 画面 |
|---|---|
| `idle` | 闲置 |
| `working` | 埋头干活 |
| `waiting` | 举牌子（最醒目） |
| `done` | 刚完成 |
| `error` | 出错 |
| `sleeping` | 睡着了 |

## 校验

提交前跑一遍：

```bash
python -m petd.tools.check_assets
```

检查：六态齐不齐、PNG 能不能打开、有没有 alpha 通道、有没有多出来的文件。
