# 美术规范

## 核心规格

| 项 | 值 |
|---|---|
| 分辨率 | **240 × 320**（竖屏） |
| 格式 | PNG，带 alpha |
| 帧数 | **每态恰好一张** —— 不分帧、不做动画 |
| 原始尺寸 | **随意** —— 会被裁切缩放到 240×320，**不拉伸** |
| 透明底 | 最好（宠物要叠在背景上） |

## 目录与命名

```
skins/
└── default/
    ├── idle.png
    ├── working.png
    ├── waiting.png
    ├── done.png
    ├── error.png
    └── sleeping.png
```

**规则**：
- 一个皮肤文件夹 = 六个状态各一张图，文件名就是状态名 + `.png`
- 状态名必须与 [状态语义](状态语义.md) 里的状态名一致
- 同一状态只有一张 —— 想要多帧就是走错模型了
- 用户自己建的放在 `petd/data/skins/<name>/`，同名时盖掉仓库那份

六张图要**同尺寸、同角色、同位置** —— 状态切换时脸不能跳。
主体画在中间偏下。

## 背景

背景是**独立于宠物**的一张图，铺满整屏。

| 项 | 值 |
|---|---|
| 分辨率 | **240 × 320** |
| 格式 | PNG（源文件格式不限，服务端统一转 PNG 存） |
| 透明度 | 不透明 —— 它是屏的底 |

```
backgrounds/
└── default.png          # 仓库自带

petd/data/backgrounds/  # 用户自己上传的，同名盖掉仓库那份
```

**背景和宠物形象是解耦的两件事** —— 换宠物不动背景，换背景不动宠物。

背景只铺在宠物那一屏。切到内容卡时背景退场，卡片用自己的底 ——
卡上要放字，背景压在上面会干扰可读性。

宠物区高度固定 240×200，**不随信息密度变化** —— 密度只管下面放几行字。

## 三种信息密度

旋钮可以切换密度档位（按住+旋转）：

| 档位 | 文字 | 用途 |
|---|---|---|
| 简洁 | 仅一行状态词 | 省空间，远处也能看 |
| 标准 | 状态词 + 一行副标题 | 默认 |
| 详细 | 状态词 + 副标题 + 会话名 | 近距离 / 无障碍 |

**宠物大小不随档位变** —— 三档用的是同一张宠物图，只是下面多几行字。

## 版式

```
┌────────────────────────┐
│                        │
│      表情区             │  ← 固定 240×200，背景铺在底下
│                        │
│                        │
├────────────────────────┤
│  状态文字区             │  ← Pi 侧 Pillow 渲染
│  「正在跑工具」          │
│  「my-train 后端」       │
└────────────────────────┘
```

- 表情区：240 × 200（固定）
- 文字区：剩余高度，档位决定显示几行
- 文字**由 petd 渲染**，不要求美术出带字的图

## 状态怎么区分

表情区贴的是那一态的图，六态各一张。**不做帧动画** —— 状态跳变时直接换图。

| 状态 | 画面 |
|---|---|
| `idle` | 闲置 |
| `working` | 埋头干活 |
| `waiting` | 举牌子（最醒目） |
| `done` | 刚完成 |
| `error` | 出错 |
| `sleeping` | 睡着了 |

## 校验

提交前跑一遍：

```bash
python -m petd.tools.check_assets
```

检查：六态齐不齐、PNG 能不能打开、有没有 alpha 通道、有没有多出来的文件。

## 版权

提交的素材请在 PR 里注明来源与授权。默认接受：
- 自己画的 → 你自己定许可，登记在 `meta.json`
- AI 生成的 → 说明用的什么工具
- 第三方 → 必须附原始授权证明

每个素材目录要有 `meta.json`，里面写清 `name` / `author` / `source` / `license`。
仓库自带的默认宠物就是这么声明的 —— 照着那个文件写。
