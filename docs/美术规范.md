# 美术规范

> 🟡 规格已定，素材未产出。美术由项目维护者提供。

## 核心规格

| 项 | 值 |
|---|---|
| 分辨率 | **240 × 320**（竖屏） |
| 格式 | PNG，带 alpha |
| 帧率 | 状态跳变帧播一次；循环帧 8–12 fps |
| 帧数 | idle 6–10 / working 4–6 / waiting 3–4 / done 4–6 / error 3–4 / sleeping 4–6 |
| 原始尺寸 | **随意** —— 会被裁切缩放到 240×320，**不拉伸** |
| 透明底 | 最好（宠物要叠在背景上） |

## 目录与命名

```
assets/
├── frames/
│   ├── idle/       idle_00.png … idle_07.png
│   ├── working/    working_00.png …
│   ├── waiting/    waiting_00.png …
│   ├── done/       done_00.png …
│   ├── error/      error_00.png …
│   └── sleeping/   sleeping_00.png …
└── skins/
    └── default/
```

**规则**：
- 状态目录名 = 状态名，必须与 [状态语义](状态语义.md) 里的状态名一致
- 帧文件用**两位**序号（`_00` → `_07`），保证字典序 = 播放顺序
- 循环帧的第一帧和最后一帧要能接上（呼吸动画常见问题）

## 三种信息密度

旋钮可以切换密度档位（按住+旋转），同一套美术要适配三档：

| 档位 | 表情区高度 | 文字 | 用途 |
|---|---|---|---|
| 紧凑 | 240×140 | 仅一行状态词 | 省空间，远处也能看 |
| 标准 | 240×200 | 状态词 + 一行副标题 | 默认 |
| 大号 | 240×280 | 状态词 + 副标题 + 会话名 | 近距离 / 无障碍 |

**实现上不是三套美术** —— 是同一套图在不同版式里缩放排布。表情区高度变了，文字区就跟着变。

## 版式

```
┌────────────────────────┐
│                        │
│      表情区             │  ← 按密度档位变高
│                        │
│                        │
├────────────────────────┤
│  状态文字区             │  ← Pi 侧 Pillow 渲染
│  「正在跑工具」          │
│  「my-train 后端」       │
└────────────────────────┘
```

- 表情区：240 × 140 / 200 / 280（紧凑 / 标准 / 大号）
- 文字区：剩余高度
- 文字**由 petd 渲染**，不要求美术出带字的图

## 皮肤包

美术可以做成独立的「皮肤包」发布：

```
skins/<skin-name>/
├── frames/…
├── palette.json      # 可选：主题色
└── meta.json         # {"name": "…", "author": "…", "license": "…"}
```

**代码与美术分开授权** —— 见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 默认角色要程序化生成

🟡 开源时需要一个**程序生成的默认角色**，让 clone 下来的人零授权风险就有宠物可跑。

- 纯代码画（几何形状 + 状态参数），输出到 `skins/default/frames/`
- 维护者的美术作为「可选皮肤包」单独发布，各自授权
- 决定这条的是**能不能商用分发** —— 见 README 的「许可证」一节

## 校验

提供个校验脚本，提交前跑一遍：

```bash
python -m petd.tools.check_assets
```

检查：尺寸是不是 240×320、alpha 通道在不在、帧数够不够、命名对不对。

## 版权

提交的素材请在 PR 里注明来源与授权。默认接受：

- 自己画的 → 你自己定许可，登记在 `meta.json`
- AI 生成的 → 说明用的什么工具
- 第三方 → 必须附原始授权证明
