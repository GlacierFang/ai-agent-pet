# 美术规范

## 核心规格

| 项 | 值 |
|---|---|
| 分辨率 | **240 × 320**（竖屏） |
| 格式 | PNG，带 alpha |
| 帧数 | **每态恰好一张** —— 不分帧、不做动画 |
| 原始尺寸 | **随意** —— 会被裁切缩放到 240×320，**不拉伸** |
| 透明底 | 最好（宠物要叠在背景上） |

## 目录与命名

```
skins/
└── default/
    ├── idle.png
    ├── working.png
    ├── waiting.png
    ├── done.png
    ├── error.png
    └── sleeping.png
```

**规则**：
- 一个皮肤文件夹 = 六个状态各一张图，文件名就是状态名 + `.png`
- 状态名必须与 [状态语义](状态语义.md) 里的状态名一致
- 同一状态只有一张 —— 想要多帧就是走错模型了
- 用户自己建的放在 `petd/data/skins/<name>/`，同名时盖掉仓库那份

六张图要**同尺寸、同角色、同位置** —— 状态切换时位置不能跳。
主体画在中间偏下。

## 背景

背景是**独立于宠物**的一张图，铺满整屏。

| 项 | 值 |
|---|---|
| 分辨率 | **240 × 320** |
| 格式 | PNG（源文件格式不限，服务端统一转 PNG 存） |
| 透明度 | 不透明 —— 它是屏的底 |

背景分**两套**，各有各的目录、清单和上传口：

| | 铺在哪 | 仓库自带 | 用户上传 |
|---|---|---|---|
| **宠物背景** | 宠物那一屏 | `backgrounds/<name>.png` | `petd/data/backgrounds/<name>.png` |
| **卡片背景** | 内容卡和骰子 | `card_backgrounds/<name>.png` | `petd/data/card_backgrounds/<name>.png` |

同名时用户那份盖掉仓库那份。

**两套互不串** —— 宠物背景那张图不会出现在卡片背景的清单里，反之亦然；
要换卡片的底，就在卡片背景那一栏自己传一张。

**背景和宠物形象是解耦的两件事** —— 换宠物不动背景，换背景不动宠物。

卡片背景不选就用卡片自己的深色渐变 —— 跟没这个功能时一模一样。
卡上要放字，所以文字区垫一条暗带 —— 用户传的亮底图上字也读得清。

文字带高度固定 240×100（在顶部），**不随信息密度变化** —— 密度只管带里放几行字。
宠物区占剩下的 240×220，在底部。

## 三种信息密度

旋钮可以切换密度档位（按住+旋转）：

| 档位 | 文字 | 用途 |
|---|---|---|
| 简洁 | 仅一行状态词 | 省空间，远处也能看 |
| 标准 | 状态词 + 一行副标题 | 默认 |
| 详细 | 状态词 + 副标题 + 会话名 | 近距离 / 无障碍 |

**宠物大小不随档位变** —— 三档用的是同一张宠物图，只是下面多几行字。

## 版式

```
┌────────────────────────┐
│  状态文字区             │  ← Pi 侧 Pillow 渲染，固定 240×100
│  「干活」                │
│  「正在跑工具」          │
│  「my-train 后端」       │
├────────────────────────┤
│                        │
│      宠物区             │  ← 固定 240×220，背景铺在底下
│                        │
└────────────────────────┘
```

- 文字带：240 × 100（顶部，固定）
- 宠物区：240 × 220（底部，固定）
- 文字**由 petd 渲染**，不要求美术出带字的图

**文字在上、宠物在下** —— 功能卡也是这个顺序，屏上两种版式统一。
宠物踩在底部，正好落在背景的地板上。

## 状态怎么区分

宠物区贴的是那一态的图，六态各一张。**不做帧动画** —— 状态跳变时直接换图。

六态的墨迹范围不一样（y=47~283），所以整幅等比缩放，**不裁到墨迹** ——
一裁，宠物切状态时就会上下跳。

| 状态 | 画面 |
|---|---|
| `idle` | 闲置 |
| `working` | 埋头干活 |
| `waiting` | 举牌子（最醒目） |
| `done` | 刚完成 |
| `error` | 出错 |
| `sleeping` | 睡着了 |

## 校验

提交前跑一遍：

```bash
python -m petd.tools.check_assets
```

检查：六态齐不齐、PNG 能不能打开、有没有 alpha 通道、有没有多出来的文件。

## 版权

提交的素材请在 PR 里注明来源与授权。默认接受：
- 自己画的 → 你自己定许可，登记在 `meta.json`
- AI 生成的 → 说明用的什么工具
- 第三方 → 必须附原始授权证明

每个素材目录要有 `meta.json`，里面写清 `name` / `author` / `source` / `license`。
仓库自带的默认宠物就是这么声明的 —— 照着那个文件写。
