## 合规判断

> 🟡 以下是判断，不是法律意见。真要卖硬件请找专业人士确认。

| 项 | 判断 |
|---|---|
| DevKitC 用 ESP32-S3-WROOM 模组 | 模组本身带 FCC/CE/SRRC 认证，基于已认证模组的成品**可能**沿用认证 —— **需核实** |
| 纯开源分发 | 不触发 CE 认证义务 |
| 卖预组装成品 | 要 Responsible Party（欧盟）/ FCC ID |
| 无线频段 | ESP32-S3 只支持 2.4GHz，无频段风险 |
| 电池 | 无电池 → 不涉及 UN38.3 运输认证 |
| 项目名带 `openclaw-` 前缀 | 可能与上游商标政策冲突 —— 发布前查一下 |

## 发布前必须解决的

1. **LICENSE**（建议 Apache-2.0 —— 比 MIT 多一层专利授权，对硬件+软件混合项目更稳）
2. **默认角色程序化生成** —— 决定「clone 下来能不能直接用」和「能不能商用分发」
3. **README 首屏 GIF** —— 「agent 干活时它在旁边打工人、等你审批时举牌子」。**这段是整个项目最值钱的素材**，但要等宠物真能跑起来
4. **维护者承诺** —— README 写明谁维护、多久看一次 issue。这不是形式，是别人敢不敢用的前提
